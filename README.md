# Т-Интенсив: риск-аналитика и ML в кредитном скоринге

Здесь лежат мои домашние задания с Т-Интенсива по риск-аналитике от Т-Банка (лето 2026). Интенсив прошёл весь путь кредитного риска: от построения и интерпретации скоринговых моделей до оценки экономики кредита через NPV и нейросетей на последовательностях транзакций.

| Папка | Тема | Что сделано |
|---|---|---|
| `01_boosting_optuna_shap` | Градиентный бустинг | LightGBM с подбором гиперпараметров в Optuna, анализ пространства поиска, интерпретация модели через SHAP |
| `02_feature_selection` | Отбор признаков | Отсев по IV, отбор признаков для бустинга на данных, упорядоченных по времени, с train / valid / test |
| `03_npv_model` | NPV-модель кредита | Добавила расчёт IRR, провела анализ чувствительности NPV по 13 параметрам, встроила в модель страховку (NPV 1062, IRR 45.85 %) |
| `04_def_rate_npv` | Кривые DEF rate | Винтажный анализ, разложение на созревание и внешние воздействия, сглаживание кривых, встраивание DEF rate в NPV и зависимость NPV от PD |
| `05_credit_approval` | Решение о выдаче кредита | EDA, модель PD, порог одобрения 0.19355 выведен из экономики кейса (+18 % / −75 % лимита), проверка на OOT через PSI; одобрено 43.8 % заявок, прибыль на OOT 91.4 млн |
| `06_nn_scoring` | Нейросети в скоринге | Предсказание дефолта по последовательности транзакций для пяти продуктов: harmonic AUC 0.7468 на тесте против 0.6718 у бейзлайна LSTM и 0.7214 у порога бустинга; отчёт в `report.pdf` |

Данные в репозиторий не выкладываю, здесь только код решений. Ноутбуки ждут файлы рядом с собой: `data_scores.csv` и `data_vintages.csv` для `04`, `historical_data.csv` и `OOT.csv` для `05`. Данные для `01`, `02` и `06` выдавались на курсе отдельно, для `06` это датасеты на Kaggle, ссылки есть в самом ноутбуке. Выводы ячеек в ноутбуках сохранены, так что результаты видно и без запуска.

Стек: Python, pandas, numpy, scikit-learn, LightGBM, Optuna, SHAP, PyTorch, matplotlib, plotly.

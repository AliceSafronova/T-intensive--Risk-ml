# Т-Интенсив: риск-аналитика и ML в кредитном скоринге

Здесь лежат мои домашние задания с Т-Интенсива по риск-аналитике от Т-Банка (лето 2026). Интенсив прошёл весь путь кредитного риска: от статистики и A/B-тестов до оценки экономики кредита через NPV и нейросетей на последовательностях транзакций. Папки идут в порядке курса, номера ДЗ в таблице совпадают с нумерацией на платформе.

| Папка | ДЗ | Тема | Что сделано | Баллы |
|---|---|---|---|---|
| `01_statistics_ab` | ДЗ 1 | Статистика и A/B-тесты | Распределения выборочных статистик и ЦПТ, оценка параметра методом максимального правдоподобия, доверительный интервал для доли теоретически и бутстрапом, расчёт размера выборки под MDE, ошибки первого и второго рода на 1000 A/B и A/A тестов | 10/10 |
| `02_logreg_woe_iv` | ДЗ 3 | Логрег, WoE и IV | Реализация WoE по бакетам с доверительными интервалами, график линейности признака, вывод IV через KL-дивергенцию, сегментная логрег-модель: бейзлайн, категориальные признаки, линеаризация, финальная модель | 19/20 |
| `03_boosting_optuna_shap` | ДЗ 4 | Деревянные модели | LightGBM с подбором гиперпараметров в Optuna, анализ пространства поиска, интерпретация модели через SHAP | 10/10 |
| `04_feature_selection` | ДЗ 5 | Отбор переменных | Отсев по IV, стабильность метрик во времени, stepwise-отбор, логрег на отобранных признаках, данные упорядочены по времени с train / valid / test | 14/15 |
| `05_credit_approval` | ДЗ 6 | System design | EDA, модель PD, порог одобрения 0.19355 выведен из экономики кейса (+18 % / −75 % лимита), проверка на OOT через PSI; одобрено 43.8 % заявок, прибыль на отложенной выборке 91.4 млн | 15/15 |
| `06_nn_scoring` | ДЗ 7 | Нейросети в скоринге | Предсказание дефолта по последовательности транзакций для пяти продуктов: harmonic AUC 0.7468 на тесте против 0.6718 у бейзлайна LSTM и 0.7214 у порога бустинга; отчёт в `report.pdf` | 20/20 |
| `07_npv_model` | ДЗ 8 | NPV-модель кредита | Расчёт IRR, анализ чувствительности NPV по 13 параметрам, встраивание страховки в модель (NPV 1062, IRR 45.85 %) | 9/10 |
| `08_def_rate_npv` | ДЗ 9 | Кривые DEF rate и NPV | Винтажный анализ, разложение на созревание и внешние воздействия, сглаживание кривых, встраивание DEF rate в NPV-модель и зависимость NPV от PD | 10/10 |

ДЗ 2 было тестом, поэтому его здесь нет.

Данные в репозиторий не выкладываю, здесь только код решений. Ноутбуки ждут файлы рядом с собой: `historical_data.csv` и `OOT.csv` для `05`, `data_scores.csv` и `data_vintages.csv` для `08`. Данные для `02`, `03`, `04` и `06` выдавались на курсе отдельно, для `06` это датасеты на Kaggle, ссылки есть в самом ноутбуке. Выводы ячеек сохранены, так что результаты видно и без запуска.

Стек: Python, pandas, numpy, scipy, scikit-learn, LightGBM, Optuna, SHAP, PyTorch, matplotlib, plotly.
